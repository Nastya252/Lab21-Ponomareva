## Тема

Коллекция List в C#.

## Что реализовано

- ввод и вывод списка задач;
- добавление и вставка;
- удаление по значению и индексу;
- поиск первого совпадения;
- проверка допустимости индексов;
- обработка пустого списка.

## Короткие ответы

1. Чем List отличается от массива и как узнать количество элементов списка?
Ответ: массив имеет фиксированную длину, заданную при создании, а `List<T>` позволяет добавлять и удалять элементы, поэтому их количество меняется во время работы. Количество элементов списка можно узнать через `Count`

2. Чем отличаются Remove() и RemoveAt()?

Ответ: `Remove()` ищет элемент по значению и удаляет только первое совпадение, возвращая `true`, если элемент найден и удалён, и `false`, если его нет в списке. `RemoveAt()` удаляет элемент по его индексу, ничего не возвращает и требует допустимый индекс

3. Почему для вставки допустим индекс Count, а для удаления — нет?

Ответ: вставка по индексу `Count` означает добавление элемента в конец списка - это позиция «после последнего элемента», и она корректна даже для пустого списка. Для удаления такого элемента не существует: индексы занятых позиций идут от `0` до `Count - 1`, поэтому удаление по индексу `Count` выходит за границы списка и приводит к исключению
